# Maintainers

## Current responsibility

| GitHub handle  | Role                            | Responsibility                                                                |
| -------------- | ------------------------------- | ----------------------------------------------------------------------------- |
| `@Mehtapozkan` | Repository owner and maintainer | Product boundary, review, releases, governance, security coordination, merges |

Maintainers act for the official Field Runtime Core repository. They do not own
contributor work beyond the rights granted by the Apache License 2.0, and their
role does not limit anyone's right to use or fork the project under that license.

## Maintainer duties

- Preserve the product constitution and evaluation-preview boundary.
- Review changes for correctness, safety, licensing, and maintainability.
- Keep implemented, planned, and unsupported behavior clearly separated.
- Record material decisions and disclose relevant conflicts.
- Coordinate releases and confidential reports when practical.
- Apply the Code of Conduct consistently.

## Appointment and departure

The repository owner appoints or removes maintainers based on sustained,
constructive contribution, judgment around consequential-work boundaries, and
ability to review responsibly. Changes must update this file and `CODEOWNERS` in a
reviewable pull request.

A maintainer who cannot participate for an extended period should mark themselves
inactive or step down. Response expectations remain those in
[SUPPORT.md](SUPPORT.md); maintainer status creates no support service level.
