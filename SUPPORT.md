# Support

Field Runtime Core is an evaluation preview for synthetic, loopback-only use. It
has no production support, availability, security-remediation, or response-time
service level.

## Public support channels

Use a GitHub issue for:

- A reproducible defect in the evaluation preview.
- A documentation gap or unclear evaluation step.
- A scoped product proposal that fits the [product constitution](PRODUCT_SPEC.md).

Choose the closest issue form and include the commit or version, environment,
reproduction steps, expected result, and actual result. Search existing issues
first. Do not include customer data, credentials, private prompts, proprietary
payloads, or other confidential information.

Maintainers review issues on a best-effort basis. There is no guaranteed reply or
fix timeline. Safety regressions, reproducible failures, and work inside the
published milestone may be prioritized; duplicate, unsupported, or out-of-scope
requests may be closed with a brief explanation.

## Confidential reports

- For a suspected vulnerability, follow [SECURITY.md](SECURITY.md).
- For sensitive community conduct, follow
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Both policies route confidential reports to GitHub's private advisory form when
GitHub makes that form available for this repository. If the form is unavailable,
do not publish report details. A public issue may request a private reporting path
without identifying people or disclosing the incident.

## Support boundary

The project does not provide production deployment approval, compliance advice,
incident response, data recovery, migration guarantees, or support for modified
forks and undisclosed environments. Community help does not change the evaluation
preview's trust boundary or create a warranty under the Apache License 2.0.
