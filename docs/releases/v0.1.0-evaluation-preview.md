# v0.1.0 Evaluation Preview

Status: published as the `v0.1.0-evaluation-preview.0` GitHub prerelease.

## What Field Runtime Core is

Field Runtime Core is an Apache-2.0-licensed, self-hosted evaluation preview of an
Enterprise Case Runtime for consequential work. Its unit of work is the complete
case—not an isolated model answer: evidence, conflicts, people, commitments,
decision options, authority, exact actions, independent verification, outcomes,
corrections, receipts, and replay lineage.

The product goal is multiplayer, attributable authority with no model-provider
lock-in. Models and agents may propose, while deterministic policy and named people
authorize. Provider-neutral case state stays in the runtime; models, agent
harnesses, memory systems, work surfaces, and connectors remain replaceable
adapters.

## Promise

Increase an experienced operator's power to resolve consequential work.

## Included

- Enterprise Case Runtime contracts and deterministic case engine.

- ECC synthetic workflow pack and 30-case Production Test.

## Boundary

This is an evaluation preview—not production software. It is synthetic,
single-node, loopback-only, unauthenticated, and has external writes disabled. Its
authority, action, verification, receipt, and learning journey is a guided
simulation; runtime enforcement of those controls begins with planned D6–D8 work.

## Roadmap after this candidate

- **D6–D8 — Trusted kernel:** governed Case sessions, controlled simulated action,
  independent verification, receipts, economics, and visible failure paths.
- **D9–D10 — Case formation and legibility:** provenance-preserving intake,
  conditional Case formation or existing-Case import, and Operational Legibility.
- **D11–D12 — Reviewed runtime and replaceable workers:** Runtime Builder followed
  by the Work Agent Runtime, gated on trustworthy D9–D10 evidence.
- **D13–D15 — Entry and intelligence:** the 25-Case Challenge, self-serve
  distribution, and receipted worker/model routing.
- **D16–D18 — Learning and real-world evidence:** correction/replay, read-only
  connectors, and a shadow-mode Production Test.
- **D19–D20 — Enterprise control and governed action:** multiplayer coordination
  followed by narrow, evidence-backed production writes.
