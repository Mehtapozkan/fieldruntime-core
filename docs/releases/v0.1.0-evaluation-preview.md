# v0.1.0 Evaluation Preview

Status: release candidate pending public-repository approval and tag.

## Promise

Increase an experienced operator's power to resolve consequential work.

## Included

- Enterprise Case Runtime contracts and deterministic case engine.
- Append-only PostgreSQL evaluation persistence.
- ECC synthetic workflow pack and 30-case Production Test.
- Loopback-only Docker Compose appliance and `fr` CLI.
- Six-action Guided Workbench.
- Apache License 2.0 governance and automated public-release checks.

## Verified release evidence

- 135/135 repository tests pass with the release-preparation boundary enabled.
- ECC passes 30/30 cases and 620/620 checks with every hard gate passing.
- `pnpm release:check` passes across 118 current files, complete reachable Git
  history, required release artifacts, pinned container images, package metadata,
  and production dependency licenses.
- Hosted CI performs fresh-volume Docker Compose startup, restart, durability,
  deduplication, and append-only smoke checks.

Hosted CI must pass again on the release-preparation pull request and final `main`
commit before the tag is created.

## Boundary

This is an evaluation preview—not production software. It is synthetic,
single-node, loopback-only, unauthenticated, and has external writes disabled.

## Source installation

Follow the [five-minute evaluation](../guides/5-minute-evaluation.md). Signed
artifacts, installers, upgrade and uninstall flows, SBOMs, and provenance remain a
later release milestone.
